小红书评论分析：如何清洗、分类与归纳用户反馈

2026-11-22 · 马哥数据采集

介绍小红书评论数据的关联、去重、文本清洗、主题分类与人工抽样复核方法。

一、评论必须保留笔记上下文

评论离开原笔记后容易被误读。建议保留笔记链接或唯一标识、笔记主题、评论文本、评论时间和采集时间。笔记表与评论表分开存储，再通过关联键连接。

二、建立清洗规则

  • 去除完全重复的记录，同时保留原始数据副本。
  • 统一空白字符和明显格式异常，不随意改写原意。
  • 将表情、链接或特殊符号按研究需要保留或单独标记。
  • 区分缺失值与真实的空文本，不要一概填成相同内容。

三、主题分类从小样本开始

先人工阅读一批评论，归纳产品体验、价格、使用方法、售后、情绪表达等初始主题。制定每类的定义和正反例，再对更大样本进行标注。允许一条评论对应多个主题，也允许“其他/无法判断”。

四、做抽样复核

抽查不同主题、不同时间和不同笔记来源的评论，检查分类是否一致。对讽刺、反问、上下文依赖和极短评论要格外谨慎，不能仅靠关键词判断情绪。

评论文本可能包含个人信息。公开展示时应做必要脱敏，避免把个别用户言论包装成整体结论。

五、输出分析结论

报告中说明样本来源、时间范围、筛选条件和分类方法。用典型主题和适量原文片段解释发现，同时说明样本偏差与结论局限。

Xiaohongshu · Comment Analysis

Xiaohongshu Comment Analysis: Cleaning and Categorizing User Feedback

2026-11-22 · Mage Data Tools

A practical approach to linking comments to posts, removing duplicates, cleaning text, categorizing themes, and manually reviewing samples.

1. Keep the Context of Each Post

Comments can be misinterpreted when separated from their original posts. Keep the post URL or identifier, post topic, comment text, comment timestamp, and collection timestamp. Store posts and comments separately, then connect them with a key.

2. Define Cleaning Rules

  • Remove exact duplicates while retaining a raw-data copy.
  • Normalize whitespace and obvious formatting issues without changing the original meaning.
  • Keep or separately flag emoji, links, and special symbols according to the research purpose.
  • Distinguish missing values from genuinely empty text instead of replacing all cases with the same value.

3. Start Topic Classification with a Small Sample

Read an initial sample manually and identify themes such as product experience, price, usage, after-sales service, and emotional reactions. Define each category with examples before labeling a larger sample. A comment may belong to multiple themes, and an other or unclear category should be allowed.

4. Review Samples

Check comments from different themes, dates, and post sources to assess consistency. Be especially careful with sarcasm, rhetorical questions, context-dependent comments, and very short text. Sentiment should not be determined by keywords alone.

Comments may contain personal information. Redact it when publishing results, and do not present isolated user statements as conclusions about an entire population.

5. Report the Findings

Describe the sample source, time range, selection criteria, and classification method. Explain findings with representative themes and a limited number of excerpts, while noting sampling bias and limitations.
