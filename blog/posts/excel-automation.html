Excel 自动化：把采集数据整理成周报

2026-11-24 · 马哥数据采集

从 CSV 导入、去重清洗、透视表到多表合并和周报模板，附常用公式表、常见报错与隐私提示。

一、为什么用 Excel 处理采集数据

采集工具导出的通常是 CSV：一行一条记录，字段固定。对大多数选题、舆情和运营任务来说，筛选、去重、透视表、做图这四件事，Excel 或 WPS 就够用，不必一上来写代码。数据量大、清洗规则复杂时，再交给 Python；两者不是替代关系。

二、CSV 打开乱码怎么办

Excel 双击 CSV 时经常按本地编码打开，中文就变成乱码。正确做法是：打开 Excel → 数据 → 从文本/CSV → 选择文件 → 编码选 UTF-8 → 加载。不要用「先改扩展名」或「记事本另存」这类偏方，容易把字段和编码一起弄坏。

三、清洗五步

  1. 备份原始文件，后续所有操作在副本上做。
  2. 去重：按评论 ID、作品链接或「链接 + 时间」删除重复值。
  3. 空值与异常：筛选空白和异常字符，先标记，不要直接删除。
  4. 日期统一：用「分列」或日期格式统一成 YYYY-MM-DD，方便排序和透视。
  5. 抽样核对：随机抽 10 条回到原视频/原博文，确认字段没有错位。

四、常用公式与功能

需求功能 / 公式说明

五、多个 CSV 怎么合并

不要把文件一个个复制粘贴。用 Power Query：数据 → 获取数据 → 从文件 → 从文件夹，合并后追加查询；字段名不一致时先统一列名，再加一列「来源文件」。以后新增文件，点「刷新」即可，不用重做。

六、把周报做成模板

固定五块：本周采集范围（平台、关键词、日期）、数据量、关键发现（3 条，附原文示例）、异常与缺口、下周计划。透视表负责汇总，图表只放 1–2 张；模板每周复制一份，只改数据和日期，避免每次重新排版。

七、常见报错与排查

中文乱码

用「从文本/CSV」导入并选 UTF-8；不要双击打开。

长数字变科学计数

导入时把该列设为文本，或先加英文单引号；微博 id、视频 id 很容易中招。

前导零丢失

把列格式设为文本再粘贴，例如以 0 开头的编号。

公式不重算

公式 → 计算选项 → 自动；或按 F9 手动重算。

文件被占用

采集过程中不要用 Excel 打开结果文件，需要查看时先复制一份。

八、隐私与合规

表格里可能包含昵称、主页、IP 属地等信息。对外分享前先删除或脱敏，不要把原始表上传到不明网盘；给客户的报告只保留必要字段和代表性样本，并注明数据来源和采集日期。

九、常见问题

需要学 Python 吗？

不一定。先用 Excel 把流程跑通，遇到重复劳动或数据量过大再考虑 Python。

WPS 能用吗？

可以，去重、透视表、Power Query 类功能在 WPS 中也有对应入口，名称略有差异。

数据量上限是多少？

Excel 单表约 104 万行；超过这个量级建议用数据库或 Python。

模板能复用吗？

可以，把清洗步骤和透视表做成模板，每周只替换数据源。

十一、三个常见误区

先清洗再备份，出错无法回退；把空值直接删掉，导致样本偏差；把所有字段都设成文本，后面没法求和和透视。建议先备份、先标记后删除，只对 id、编号类字段用文本格式；公式和透视表尽量基于原始列，不要反复复制粘贴。

十二、清洗日志怎么写

记录四件事：数据来源、清洗步骤、排除规则、输出文件版本。下次复用或交接时，别人能看懂你为什么删了某条数据；出现争议时，也能快速定位到具体批次。

十三、一份可复用的检查清单

  1. 原始文件已备份。
  2. 编码、列名、日期格式已统一。
  3. 去重键已确定。
  4. 空值和异常已标记。
  5. 已抽样回到原文核对。
  6. 报告注明数据范围和采集日期。

把清单贴在模板第一行，每次照着做，能省掉大部分返工；规则变了，记得同步更新日志和模板。另外，模板不必追求复杂：能稳定跑完、别人看得懂，比堆满公式更重要；每周花 10 分钟复盘一次，比月底补一周的数据更省力，也更容易坚持下去。

1. Why Use Excel for Collected Data

Collection tools usually export CSV: one row per record with fixed columns. For most research, public-opinion, and operations tasks, filtering, deduplication, pivot tables, and charts are enough in Excel or WPS. Move to Python when the data or cleaning rules outgrow a spreadsheet.

2. Fix Garbled CSV

Double-clicking a CSV often uses the local encoding and garbles Chinese. Use Data → From Text/CSV → choose the file → Encoding: UTF-8 → Load. Avoid renaming the extension or re-saving in Notepad.

3. Five Cleaning Steps

  1. Back up the raw file and work on a copy.
  2. Deduplicate by comment ID, video URL, or URL plus time.
  3. Flag empty and abnormal values instead of deleting them.
  4. Normalize dates to YYYY-MM-DD for sorting and pivots.
  5. Spot-check ten records against the original source.

4. Useful Formulas and Features

5. Merge Multiple CSV Files

Do not copy and paste file by file. Use Power Query: Data → Get Data → From File → From Folder, then append queries. Align column names and add a source-file column; refresh after adding new files instead of rebuilding.

6. Build a Weekly Report Template

Keep five blocks: collection scope (platform, keyword, date), row count, three key findings with examples, anomalies and gaps, and next week's plan. Use a pivot table for aggregation and one or two charts; copy the template each week and replace the data source.

7. Common Errors

Garbled text

Import as UTF-8 through From Text/CSV instead of double-clicking.

Long numbers in scientific notation

Set the column to Text during import; IDs are easily affected.

Lost leading zeros

Format the column as Text before pasting codes that start with zero.

Formulas not recalculating

Set calculation to Automatic or press F9.

File locked

Do not open the CSV in Excel during collection; copy it first.

8. Privacy and Compliance

Tables may contain nicknames, profiles, and IP locations. Remove or mask them before sharing, avoid uploading raw data to unknown drives, and keep only necessary fields in client reports.

9. FAQ

Do I need Python?

Not necessarily. Build the workflow in Excel first, then move to Python when repetition or volume grows.

Does WPS work?

Yes; the features exist with slightly different names.

What is the size limit?

About 1.04 million rows per sheet; beyond that, use a database or Python.

Can I reuse the template?

Yes, keep the cleaning steps and pivot table and replace the data source each week.

11. Three Common Mistakes

Cleaning before backing up, deleting empty values outright, and formatting every column as text. Back up first, flag before deleting, and use text format only for IDs and codes.

12. Keep a Cleaning Log

Record the source, cleaning steps, exclusion rules, and output version so the next person can see why a record was removed and which batch it came from.

13. A Reusable Checklist

  1. Raw file backed up.
  2. Encoding, column names, and dates unified.
  3. Deduplication keys defined.
  4. Empty and abnormal values flagged.
  5. Sample verified against the source.
  6. Report states data scope and collection date.
